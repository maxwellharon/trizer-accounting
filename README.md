# Trizer Mwende Njoroge — Single-page portfolio website

A responsive, animated one-page professional website for executive assistance, online business management, creator operations, and financial support.

## Files

- `index.html` — complete semantic page content and section structure.
- `styles.css` — browser-ready styling, responsive layouts, hover states, and motion.
- `styles.scss` — Sass source and design tokens; styles are mirrored in the CSS build.
- `script.js` — mobile navigation, scroll reveals, achievement counters, header state, and current year.

## Run locally

Open `index.html` in a modern browser. No build step or JavaScript framework is required.

## Before publishing

1. The photographs are remote Unsplash images used as workspace imagery, not as a likeness of Trizer. Replace them with approved brand photos if available.
2. The contact details and Calendly link are based on the supplied CV and existing Google Sites page. Confirm they are still current before launch.
3. The contact links open email, phone, LinkedIn, or Calendly. There is no server-side contact form or backend in this static site.
4. If compiling `styles.scss` after future changes, use Sass to generate `styles.css` and keep both files in sync.

## Accessibility & motion

The site includes a skip link, keyboard-dismissable mobile navigation, semantic landmarks, image alt text, visible CTA labels, responsive layouts, and a reduced-motion fallback.
